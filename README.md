- Fully responsive

- Include tabs:
  + Home

  + About
  + Contact

5. Contact Page:

  "Let's work together"

- Consistent spacing (use a grid system)
- Rounded corners
- Soft blue glow accents
- Clean typography hierarchy

Animations:
- Smooth hover effects (scale + glow)
- Fade-in on scroll
- Subtle transitions (0.3s–0.5s)

UX:
- Easy to navigate
- Focus on visual work first
- Avoid clutter

Important:

- Keep layout structured and consistent
- Make it look like a professional Behance/Dribbble-level portfolio

Output:

- Clean, well-organized code
